# 02 — 统一 Dashboard 与风险分析数据 read-model

**What to build:** 让首页、登录页、风险分析页和 AI 相关展示使用统一的监测概览与预测结果，消除分散的静态数字；用户仍能使用原有的趋势切换、预测周期、日期选择、刷新和导出功能。

**Blocked by:** 01 — 建立后端接入文档和文件更名记录

**Status:** ready-for-agent

- [ ] 首页、登录页、风险分析页不再各自维护重复的诱集数量、温湿度和风险摘要
- [ ] Dashboard 与风险分析使用集中维护的 mock read-model
- [ ] 风险图表、摘要、详细表格和模型解读使用同一份预测结果
- [ ] 预测结果为空或不完整时显示可理解的空状态，不发生页面崩溃
- [ ] 不需要环境数据的页面不再被全局环境 provider 强制绑定
- [ ] 现有视觉效果和页面交互保持一致
